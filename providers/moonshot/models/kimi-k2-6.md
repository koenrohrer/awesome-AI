# Kimi K2.6 `[provider-doc]`

*Last reviewed: 2026-08-16.*

## At a glance

- Provider: Moonshot AI
- Model ID: `kimi-k2.6`
- Tier: Earlier multimodal general-purpose tier
- Context window: 262,144 tokens (documented as 256K)
- Modalities: text and image input
- Reasoning: thinking and non-thinking modes
- Availability: hosted API and open weights
- Official docs: [model list](https://platform.kimi.ai/docs/models), [Kimi K2.6 pricing](https://platform.kimi.ai/docs/pricing/chat-k26)

## What it is

Kimi K2.6 is Moonshot's earlier multimodal general-purpose model for text, vision, dialogue, and agent tasks, with selectable thinking and non-thinking modes. Kimi K3 now occupies the flagship tier, and `kimi-k2.7-code` is the coding-focused derivative built on K2.6. [Model list](https://platform.kimi.ai/docs/models), [Kimi K2.7 Code quickstart](https://platform.kimi.ai/docs/guide/kimi-k2-7-code-quickstart).

## Pricing

As reviewed on 2026-08-16, the platform lists $0.16 per 1M cache-hit input tokens, $0.95 per 1M cache-miss input tokens, and $4.00 per 1M output tokens. Prices exclude applicable taxes. Pricing is date-sensitive; recheck the live pricing page before production use. [Kimi K2.6 pricing](https://platform.kimi.ai/docs/pricing/chat-k26).

## Open weights

Moonshot publishes K2.6 weights on Hugging Face. Hosted API access and the open-weight release are separate surfaces; check the model card and its license before self-hosting. [Kimi K2.6 on Hugging Face](https://huggingface.co/moonshotai/Kimi-K2.6).

## Public system card availability

Moonshot does not publish a public system-card hub. The model list, pricing pages, and Hugging Face model cards are the official public sources.
