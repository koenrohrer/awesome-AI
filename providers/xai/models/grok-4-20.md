## What it is

Grok 4.20 is a previous-generation reasoning model with function calling and structured outputs. Its model page remains live, but the current models catalog directs general and code workloads to Grok 4.5.

Requests beyond 200,000 context tokens use a separate higher long-context price tier. Check the live model page before budgeting.

## Public system card availability

xAI does not currently publish a public system-card hub comparable to Anthropic/OpenAI. The docs overview and model pages are the main official sources.
