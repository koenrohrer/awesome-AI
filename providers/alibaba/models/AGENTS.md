# Agent Guide: Alibaba Models

This directory contains individual Qwen model pages.

## Rules

- State whether a page describes a hosted Model Studio service, an open-weight release, or both.
- Hosted Model Studio IDs and open-weight repositories are separate surfaces. Do not infer one from the other.
- Read the specific model card's license file before making any commercial-use claim. Qwen licenses vary by release.
- Cite the Qwen blog, Hugging Face model cards, ModelScope, and Model Studio docs directly.
- Use tables by default for comparable model facts and comparisons.
- Include benchmark tables only when the benchmark has a named source, date, and methodology.
