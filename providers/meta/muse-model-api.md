# Meta Model API and Muse Spark 1.1 `[provider-doc]`

*Last reviewed: 2026-08-06.*

## At a glance

- Provider: Meta
- Product surface: Meta Model API
- Hosted model: Muse Spark 1.1
- Availability: Public preview
- Context window: 1M tokens
- Official announcement: [Introducing Muse Spark 1.1](https://ai.meta.com/blog/introducing-muse-spark-meta-model-api/)

## What it is

The Meta Model API is Meta's first-party hosted developer surface for Muse Spark 1.1. Meta describes Muse Spark 1.1 as a multimodal reasoning model for agentic tasks, tool use, computer use, and coding.

This hosted surface is distinct from Meta's Llama releases. Meta distributes Llama model weights under the Llama Community License; the Muse Spark 1.1 announcement describes public-preview API access and does not announce downloadable Muse Spark weights.

## Availability

Developers can access Muse Spark 1.1 through the Meta Model API public preview. The model also powers Thinking mode in the Meta AI app and on `meta.ai`.

Meta's launch post documents a 1M-token context window. It does not publish stable general-availability or downloadable-weight status, so production users should recheck the API documentation before pinning availability or pricing assumptions.
