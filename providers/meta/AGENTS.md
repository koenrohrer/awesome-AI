# Agent Guide: Meta

This directory covers Llama-family open weights, adjacent Meta safety models, open-weight Muse releases, and Meta's hosted Muse API and product surfaces.

## Rules

- Verify current public artifacts against Meta's own HuggingFace organizations (`meta-llama`, `meta-models`) and Meta's own docs at `ai.meta.com`, `about.fb.com`, `developer.meta.com`, and `dev.meta.ai`.
- Do not write specs sourced from news coverage. If a claim appears only in third-party press, omit it or mark it reported-not-confirmed.
- Check the exact license per artifact before commercial-use claims. Llama Community License and Apache 2.0 both appear in this directory.
- Distinguish base models, multimodal models, and safeguard models.
- Keep the distribution stories separate per artifact: downloadable weights, hosted API, and Meta consumer product surfaces are three different things, and Muse spans all three.
