# Agent Guide: Meta Models

This directory contains individual model pages for Meta's downloadable weights: Llama, Meta safeguard models, and open-weight Muse releases.

## Rules

- Cite exact HuggingFace model cards for context, modalities, license, and safety claims. Llama lives under `meta-llama`; open-weight Muse models live under `meta-models`, and the license differs with the org.
- Keep deployment and prompt-format caveats model-specific.
- Note when a model is a classifier or safeguard rather than a general assistant model.
- Use tables by default for comparable model facts and comparisons.
- Include benchmark tables only when the benchmark has a named source, date, and methodology.
