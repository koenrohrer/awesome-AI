- Tier: Legacy hosted text tier; M3 is current

## What it is

MiniMax M2.5 is a hosted text model that MiniMax positions around coding, tool calling, search, and productivity workloads. The API overview still lists it alongside `MiniMax-M2.5-highspeed`, while M3 is the current top M-series line.

## Public system card availability

MiniMax does not currently publish a public system card for M2.5.
